# Fase4-Programacion-SoftwareFJ
Sistema Integral de Gestión de Clientes, Servicios y Reservas - UNAD Fase 4

## Descripción del proyecto

Software FJ es un sistema desarrollado en Python que permite gestionar clientes, servicios y reservas mediante programación orientada a objetos (POO).

El proyecto busca facilitar el registro de clientes, la administración de servicios y el procesamiento de reservas, incorporando validaciones, manejo de excepciones y registro de eventos.

## Funcionalidades principales

- Registro y validación de clientes.
- Gestión de reservas de salas.
- Alquiler de equipos.
- Registro de asesorías especializadas.
- Creación, confirmación y cancelación de reservas.
- Cálculo de costos con descuentos e impuestos.
- Manejo de excepciones personalizadas.
- Registro de operaciones mediante archivos de log.

## Tecnologías utilizadas

- Python 3.
- Programación orientada a objetos.
- Clases abstractas, herencia y polimorfismo.
- Encapsulamiento.
- Manejo de excepciones.
- Módulo logging.

## Estructura del proyecto

- `main.py`: programa principal y ejecución de pruebas.
- `entidades.py`: clases de entidades y clientes.
- `servicios.py`: clases de servicios y sus especializaciones.
- `reserva.py`: gestión y procesamiento de reservas.
- `excepciones.py`: excepciones personalizadas.

## Ejecución

Para ejecutar el sistema desde una terminal con Python instalado, utiliza:

```bash
py main.py
```

El programa ejecutará automáticamente las pruebas de funcionamiento.
